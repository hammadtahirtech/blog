# Blog
I built this project when I was 14 and starting to explore backend development beyond just making things look good on the screen.

It was a simple blog application featuring:

* User authentication
* Posts
* Comments
* CRUD operations
* A basic blog interface

Looking back, the CSS is rough and there are plenty of things I'd do differently today. But this project was a milestone for me because it was where CRUD finally clicked. For the first time, I understood how data could move through an application, be stored, updated, and displayed back to users.

That realization unlocked a whole new side of web development and changed how I approached building projects from then on.

I'm sharing it today as a snapshot of that stage in my learning—and yeah, it's open source 😀.


### Note: It could only run if your computer has mongodb, otherwise, it'd not work because it depends entirely on local mongodb
